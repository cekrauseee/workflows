Desarrollé Workflows para organizar tareas recurrentes de ingeniería en procedimientos con objetivos, límites y criterios de finalización explícitos.

El proyecto reúne siete skills para la orquestación, los worktrees, los commits, las pull requests, las revisiones, la documentación y las entregas en HTML. Cada una puede instalarse y utilizarse de forma independiente.

## Procedimientos con límites definidos

Cada skill guía las decisiones importantes para una tarea concreta. Una revisión debe seguir los criterios solicitados y relacionar sus observaciones con evidencias. Una pull request debe explicar el problema, el comportamiento resultante y las verificaciones realizadas. Un commit debe reunir un cambio coherente.

Las instrucciones también permiten reutilizar el contexto existente y las verificaciones mientras sigan siendo válidos. Se amplía la investigación cuando falta información relevante.

El paquete está compuesto por instrucciones y metadatos, sin runtime, scripts de ejecución ni hooks propios. La ejecución utiliza las herramientas y los permisos del entorno en el que se instalan las skills.

## Responsabilidad sobre la tarea completa

Durante la orquestación, el coordinador define los objetivos, distribuye el trabajo, resuelve las dependencias y comprueba que los resultados respondan a la solicitud. Los agentes encargados de la ejecución asumen la investigación, las decisiones técnicas, la implementación, la integración y la verificación.

Cada asignación debe indicar el comportamiento esperado, los límites y el contexto necesario. Cuando una entrega está incompleta, el coordinador describe lo que falta y devuelve la tarea al agente responsable.

Esta división mantiene la responsabilidad técnica en manos de quien ejecuta el trabajo. El coordinador gestiona los resultados y las dependencias entre tareas, mientras el agente responsable lleva el trabajo hasta su conclusión.

Workflows puede utilizarse junto con Continuity: el primero guía los procedimientos de ejecución; el segundo conserva los conocimientos y las contribuciones entre tareas y proyectos.
